CMS Magic Extension - Exclusion Test

Test Instructions:

  1. Make sure the CMS Magic extension is installed and enabled
  2. Navigate to each test URL below
  3. Check the browser console for exclusion messages
  4. Verify that no "CMS Magic: ACTIVE" indicator appears
  5. Verify that no auto-fill functions are applied

What to Look For:

  • Console Messages: Look for "CMS Magic: Page is excluded from functionality" on excluded URLs
  • Visual Indicator: "CMS Magic: ACTIVE" should NOT appear on excluded URLs
  • Auto-fill: No automatic form filling should occur on excluded URLs
  • Buttons: No CMS Magic buttons should appear on excluded URLs

Console Commands for Testing:

Open browser console (F12) and run these commands to test:

// Check if CMS Magic is initialized
console.log('CMS Magic initialized:', window.cmsMagicInitialized);

// Check current URL
console.log('Current URL:', window.location.href);

// Check for test indicator
console.log('Test indicator exists:', !!document.getElementById('cms-magic-test-indicator'));
