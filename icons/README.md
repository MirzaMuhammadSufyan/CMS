# CMS Magic Icons

This directory contains the extension icons for CMS Magic.

## Required Icons

The extension requires the following icon sizes:
- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

1. Open `create-icons.html` in your browser
2. Right-click on each canvas and "Save image as..."
3. Save them as `icon16.png`, `icon32.png`, `icon48.png`, and `icon128.png` respectively
4. Place the PNG files in this `icons/` directory

## Icon Design

The icons feature:
- Gradient background (purple to blue)
- White magic sparkle (✨) emoji
- Clean, modern design
- High contrast for visibility

## Alternative

If you prefer to create your own icons:
- Use any image editor (Photoshop, GIMP, Canva, etc.)
- Create square images with the required dimensions
- Use a magic/sparkle theme to match the extension
- Ensure good contrast and visibility at small sizes
